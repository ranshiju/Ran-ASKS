# Writer 自检清单

> 主流程见 `operations/WRITE.md`。本清单用于交付前的最小检查，不替代事实回溯和实际渲染验证。

## 全部交付物

- [ ] 用途、受众、语言、格式、篇幅/页数已确认或作出合理默认
- [ ] 具体事实（时间、机构、头衔、数字、项目、成果）可回溯来源
- [ ] 能力/影响类表述与证据强度匹配；无证据主张已删除或标为待补
- [ ] 无未经授权的敏感信息、对外承诺或他人信息
- [ ] 文件保存于 `projects/`，未修改任何 `raw/` 文件

## 文体与内容

- [ ] 发言稿/公文：结构符合对应模板，原则性表达有事实锚点
- [ ] 简历/简介/合作材料：优先呈现与用途直接相关的成果和经历，不机械罗列履历
- [ ] 修改任务：保留未要求变动的有效内容与版式
- [ ] 含 `[[wikilink]]` 的 Markdown 已运行 `.scripts/check_wikilinks.py`

## 办公文档与版式

- [ ] Word/PDF 已生成且可打开
- [ ] 指定纸张、页数、字体、表格、标题和页脚均符合要求
- [ ] 已实际渲染并检查页数、溢出、截断、重叠和可读性
- [ ] 无法渲染时已在交付说明中如实说明限制

## 交付说明

- [ ] 最终答复列明绝对文件路径、格式和已完成验证
- [ ] 列明关键待补事实或未验证项（若有）
- [ ] 未自动摄入；如用户要求摄入，已转入 Ingest 流程
