# 公文模板

> 适用：通知、请示、报告、批复、会议纪要等正式公文。
> 风格规则来源：`memory/MEMORY.md` Word 文档格式规范 + 国家公文格式标准（GB/T 9704）。

---

## 结构骨架

1. **标题**：发文机关 + 关于 + 事由 + 文种（如《首都师范大学物理系关于XX的通知》）
2. **主送机关**：收文单位全称
3. **正文**
   - 缘由段：为什么发这个文（背景、依据）
   - 事项段：具体内容（分条列出）
   - 结尾段：执行要求或希望语
4. **落款**：发文机关全称
5. **日期**：YYYY年MM月DD日

## 文种格式差异

| 文种 | 特殊要求 |
|------|----------|
| 通知 | 结尾用"特此通知"或"请遵照执行" |
| 请示 | 一文一事，结尾用"以上请示，请批复" |
| 报告 | 不得夹带请示事项，结尾用"特此报告" |
| 批复 | 引述请示文号，结尾用"此复" |
| 会议纪要 | 纪实性，不加评论，用"会议认为""会议决定" |

## 风格指引

- **语言规范**：使用书面语，不用口语化表达
- **一文一事**：请示类公文只谈一件事
- **层次清晰**：内容较多时用"一、""（一）""1.""（1）"分级
- **时间明确**：涉及期限的写明具体日期
- **引用规范**：引用上级文件时写全称 + 文号
- **数字规范**：正式公文中日期、金额等使用阿拉伯数字

## 常见段落模式

**缘由段：**
- "根据《XX》（XX〔2024〕X号）文件精神，为做好XX工作，现就有关事项通知如下："
- "为贯彻落实XX要求，进一步推进XX，经研究，决定XX。现将有关事项通知如下："

**事项段：**
- "一、XX。各部门应于XX前完成XX。"
- "二、XX。具体要求如下：（一）XX；（二）XX。"

**结尾段：**
- "特此通知。"
- "以上请示，请批复。"
- "请各相关部门认真贯彻落实。"
