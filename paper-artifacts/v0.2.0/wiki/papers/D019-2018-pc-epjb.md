# Exotic entanglement scaling of Heisenberg antiferromagnet on honeycomb lattice

> **作者**：Cheng Peng、Shi-Ju Ran、Maciej Lewenstein、Gang Su | **发表**：Eur. Phys. J. B
> **核心贡献**：在 honeycomb 晶格上 spin-1/2 各向异性 Heisenberg 反铁磁体中，DMRG 截断维度 χ 下的纠缠熵在二聚体相呈线性标度、在 Néel 相呈对数标度，可作为区分两相的判据。

## Navigation

本文研究 honeycomb 晶格上 spin-1/2 各向异性 Heisenberg 反铁磁体在 DMRG 截断维度 χ 下纠缠熵（EE）与纠缠谱（ES）的标度行为。重点刻画有能隙二聚体相下 EE 的意外线性收敛，以及无能隙 Néel 相下 EE 的对数增长，并从 Schmidt 系数分布解释线性来源。最后讨论 OB / PB / IB 三类边界条件及格点编号对结果的影响，以验证该标度判据的稳健性。

## 研究方向定位

以 DMRG 计算 honeycomb 晶格 spin-1/2 各向异性 Heisenberg 反铁磁体在二聚体相与 Néel 相的纠缠熵随截断维度 χ 的标度行为，并从纠缠谱的角度给出物理解释[^r1]。

## Content

### 背景：低维量子模拟中的纠缠标度

对于 Landau–Ginzburg 范式失效的量子相（分数量子霍尔态、量子自旋液体等）以及临界系统，量子纠缠被视作刻画其多体物理的关键工具。1D 临界体系中，纠缠熵与截断维度 χ 之间通常呈对数发散，并被用于提取 CFT 的中心荷等临界信息[^r2]。然而，二维及以上体系的纠缠标度研究较少，且 TN 方法（如 MERA、PEPS）在二维的优化仍不成熟，DMRG 仍是常用的准一维模拟手段[^r3]。

### 模型与边界条件

哈密顿量为 honeycomb 晶格上 spin-1/2 各向异性 Heisenberg 模型，含 J 与 J′ 两种键耦合。在热力学极限下，J/J′ < J^c = 0.5(4) 时基态为有能隙二聚体相，J^c < J/J′ ≤ 1 时为半经典 Néel 相；论文约定 J′ = 1 作为能量尺度[^r4]。作者使用 DMRG（MPS 拟态下的一维算法），并测试三种边界条件以检验标度行为的稳健性：

- **OB**：32-site 有限团簇[^r5]。
- **PB**：32-site 圆环（或柱面），图 2 即基于此条件[^r6]。
- **IB**：利用 DMRG on trees 数值确定的纠缠 bath 站点，使有限尺寸模型逼近无穷大系统的 32-site 团块[^r7]。

由于 DMRG 本质上是一维算法，必须指定格点排序，格点编号对结果的潜在影响将在第 3.3 节讨论[^r8]。

### 二聚体相与 Néel 相的纠缠标度

数值结果显示，两相在 ES 与 EE 上呈现截然不同的模式：

- **二聚体相**：ES 表现出有明显能隙、并发生简并的结构，EE 随 χ 呈线性增长直至饱和到一个较小值[^r9]。
- **Néel 相**：ES 平滑、无显著简并，EE 随 χ 呈对数式增长[^r10]。

### 线性标度的起源

对 EE 在二聚体相线性饱和现象的分析表明：线性行为并非来自单一、连续的 Schmidt 系数，而是源于一个主导 Schmidt 数加上 n 个与之（近）简并、但远小于主导值的次主导 Schmidt 数。简并度 n 对应于将边界附近的某个 dimer 激发到三重态之一时，所产生的近简并领头激发的数目[^r11]。

### 结论与意义

研究揭示 dimer 相与 Néel 相在纠缠标度上的非平凡差异：可在 χ < n+1 的较小截断维度下直接观测 EE 对 χ 的线性标度，作为判断系统是否处于有能隙 dimer 相的简便判据[^r12]。
