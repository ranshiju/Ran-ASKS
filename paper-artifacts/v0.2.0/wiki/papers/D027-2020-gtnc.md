# Generative tensor network classification model for supervised machine learning

> **作者**：Zheng-Zhi Sun、Cheng Peng、Ding Liu、Shi-Ju Ran、Gang Su | **发表**：Phys. Rev. B 101, 075135 (2020)
> **核心贡献**：提出生成式张量网络分类（GTNC）模型，以矩阵乘积态（MPS）为生成张量网络，按保真度最大原则在多体希尔伯特空间中对样本进行监督分类。[^r1]

## Navigation

GTNC 是一种面向监督学习的量子启发分类器。它将经典图像通过特征映射（feature map）编码到多体希尔伯特空间后，为每一类样本单独训练一个生成式张量网络（以 MPS 实现），分类时比较样本与各类生成态之间的保真度（fidelity）。[^r2][^r3] 在 MNIST 与 fashion-MNIST 基准数据集上，GTNC 在准确率与超参数依赖程度方面均优于朴素贝叶斯分类器与多种 SVM 设定。[^r4][^r5] 本文还分析了特征映射、键维度（bond dimension）与量子纠缠在避免过拟合中的作用。[^r6]

## 研究方向定位

本文研究在多体希尔伯特空间中以矩阵乘积态（MPS）为生成模型对监督分类问题中的图像样本进行聚类与判别的方法，核心问题在于显式特征映射、生成式 MPS 训练与按保真度分类三者协同所带来的准确率与超参数鲁棒性。[^r7]

## Content

### 模型架构：作为生成态的矩阵乘积态

GTNC 的生成张量网络选用 MPS（matrix product state）形式。一个由 L 个张量组成的 MPS 写作 $\Psi_{s_1 s_2 \dots s_L} = \sum_{\alpha_1 \dots \alpha_{L-1}} T^{[1]}_{s_1,\alpha_1} T^{[2]}_{s_2,\alpha_1 \alpha_2} \cdots T^{[L]}_{s_L,\alpha_{L-1}}$，其中每个 $T^{[l]}$ 是位于第 l 个格点、维度为 $(d \times \chi \times \chi)$ 的张量，$\alpha_l$ 为虚键（virtual bond），$\{s_n\}$ 为实键（physical bond）。[^r8] 键维度 $\chi$ 决定了 MPS 的参数数量及其能捕获的纠缠上界。收缩所有虚键后，$\Psi$ 落在维度随 L 指数增长的 $[\mathbb{V}^d]^{\otimes L}$ 中，但得益于张量网络结构，参数总数约为 $L d \chi^2$，仅随 L 线性增长。[^r9]

### 训练流程：从特征映射到生成态

训练前，先用一个一一对应的"特征映射"（feature map）把图像映射到多体希尔伯特空间中的向量。例如，将归一化像素 $x_i \in [0,1]$ 映射为二维向量 $\mathbf{s}_i = [\cos(\frac{\pi}{2} x_i), \sin(\frac{\pi}{2} x_i)]^T$，使一张 L 像素图像成为 $\mathbf{v} = \prod_{\otimes i} \mathbf{s}_i$，可视为 L 个量子比特（自旋 1/2）的直积态；亦可推广到 $d>2$ 的广义特征映射。[^r10][^r11] 之后为每一类 $c=1,\dots,K$ 训练一个生成 MPS $\Psi^{(c)}$，由 Han 等人提出的梯度算法通过最小化 Kullback–Leibler 散度来拟合对应类样本的联合概率分布。[^r12]

### 按保真度分类

给定待分类样本 $\mathbf{v}$，GTNC 通过比较它与各类生成态 $\Psi^{(c)}$ 之间的保真度 $f_c = |\mathbf{v}^\dagger \Psi^{(c)}|$ 来决定类别，分类规则为 $\arg\max_c f_c$。[^r13] 当 MPS 被用作生成张量网络时，对应的具体模型被作者称为生成式 MPS 分类器（GMPSC）；论文在正文中以 GMPSC 展开算法分析与数值结果，并提示其伪代码见补充材料。[^r14] GMPSC 的训练计算复杂度为 $O(N L \chi^2)$，明显低于判别式 MPS 分类器（DMPSC）的 $O(N K L \chi^2)$。[^r15]

### 性能与对超参数的依赖

在 MNIST 上，GMPSC 在 $\chi \geqslant 64$ 时取得 98.2% 的测试准确率，显著超过朴素贝叶斯分类器。[^r16] 与卷积神经网络等判别式模型的最优结果（MNIST 99.77%、fashion-MNIST 92.54%）相比，GTNC 的准确率仍有差距，但作者强调这些判别式最优结果依赖精心选择的架构与超参数，而 GTNC 在不同数据集上使用了相同的 MPS 架构与同一特征映射等超参数。[^r17] 例如，把 GTNC 的特征映射直接作为 SVM 的核函数时，测试准确率低于 30.0%，说明 SVM 性能强烈依赖核选择。[^r18]

### 与 SVM 的相似与差异

GTNC 与 SVM 都将样本映射到更高维空间以便于分类，其特征映射/核函数均满足 Mercer 条件。[^r19] 二者的关键区别在于：GTNC 的映射方式显式且对超参数依赖较弱，而 SVM 通常使用隐式映射并对软间隔等超参数高度敏感；GTNC 的判别依据是样本到生成模型之间的距离（即保真度），SVM 则是寻找带软间隔的分类边界。[^r20][^r21]

### 基线对照与自然聚类

作者引入"懒学习"基线模型 I：对第 c 类，直接令 $\tilde{\Psi}^{(c)} = \sum_{\mathbf{v}\in c} \mathbf{v} / \sqrt{N_c}$，再用同一保真度规则分类。[^r22][^r23] GMPSC 只需适中的键维度（$1 \ll \chi \ll d^L$）就能超过基线，说明 MPS 截断相当于丢弃冗余信息并保留高纠缠基底，从而提高了识别效率与准确率。[^r24] 在多体希尔伯特空间中，类内保真度远高于类间保真度（数据小至 $10^{-16}$ 的部分在图中被截断为平坦圆盘），直观展示了样本在该空间中自然聚类的现象。[^r25][^r26]

### 纠缠与过拟合控制

MPS 的键维度截断与正则化（canonicalization）丢弃对纠缠熵 $H_2(\chi) \leqslant \ln \chi$ 贡献较小的基底。[^r27] 实验表明，对识别重要的信息被保留在纠缠较大的基底中，这使得 GMPSC 的过拟合能以可控方式被量子纠缠结构所约束。[^r28]

### 总结与意义

作者把 GTNC 定位为一种量子启发的生成式监督学习模型：核心是为每类样本在多体希尔伯特空间中独立训练生成 MPS，再以最大保真度分类；它在准确率上超过既有的（判别式）TN 机器学习方法、朴素贝叶斯与 SVM，并显著降低对超参数的依赖。[^r29][^r30] 文章明确给出的未来方向包括：通过优化架构与超参数进一步提升 GTNC 准确率，以及探索基于量子电路实现此类机器学习方案。[^r31][^r32]
