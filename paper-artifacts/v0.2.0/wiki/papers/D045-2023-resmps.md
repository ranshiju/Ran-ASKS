# Residual matrix product state for machine learning

> **作者**：Ye-Ming Meng、Jing Zhang、Peng Zhang、Chao Gao、Shi-Ju Ran | **发表**：2023
> **核心贡献**：将 matrix product state (MPS) 与残差结构结合，提出 Residual matrix product state (ResMPS)，在 MNIST 与 Fashion-MNIST 上以更少参数取得优于既有 tensor network 模型的稳定性、效率与表达能力。[^r1]

## Navigation

本文针对 tensor network 在经典机器学习上与神经网络仍存在精度差距的问题，把 MPS 与残差神经网络思想融合，提出 ResMPS 及其两个具体变体 sResMPS（线性）与 aResMPS（非线性 + dropout）。ResMPS 的可训练参数不再只是权重，而是输入特征的函数；论文同时从多项式展开的角度给出 ResMPS 与 Factorization Machines / Exponential Machines 的等价性，并给出避免梯度消失/爆炸的条件。论文在 SciPost Physics 2023 年发表，代码基于 PyTorch 开源。[^r1][^r2][^r3]

## 研究方向定位

研究对象为面向图像分类的 tensor network 模型 MPS；核心问题是 MPS 相对神经网络在精度、稳定性与表达力上的差距；方法是将 MPS 各层的"hidden"映射改为输入特征的函数、引入残差捷径、非线性激活与 dropout，构建 ResMPS。[^r1]

## Content

### 残差化的矩阵乘积态：ResMPS 的结构

ResMPS 的各层把"隐藏"特征映射到分类输出，而每一层的变分参数本身是样本特征（如像素）的函数，这与神经网络把特征在前馈层中逐层映射的结构不同。[^r1] 残差结构引入信息高速公路、非线性激活与 dropout，使 ResMPS 兼具多项式网络与 tensor network 的可解释性。[^r1] 在 Fashion-MNIST 的对比中，aResMPS 的准确率超过既有 state-of-the-art tensor network 方法以及 AlexNet，但仍逊于堆叠卷积层的 ResNet。[^r2][^r3]

### 两种具体变体：sResMPS 与 aResMPS

- **sResMPS**：ResMPS 的线性简化版。在 Fashion-MNIST 上它揭示了 MPS 中存在通道冗余；通过丢弃冗余通道，参数规模减半但保持一致的精度。[^r2][^r3]
- **aResMPS**：ResMPS 的一般形式，加入激活函数与 dropout。非线性增强模型表达力，dropout 提升泛化能力。[^r3]

### 与多项式展开的联系

论文给出 ResMPS 的多项式展开视角，并在此框架下推导梯度消失/爆炸出现的条件，用以指导特征设计与稳定收敛。[^r3] 同时建立 ResMPS 与 Factorization Machines、Exponential Machines 等多项式网络的等价性；数值证据显示高阶项贡献不显著，有助于理解 MPS 与 ResMPS 的工作机理。[^r3]

### 实验设置

- **数据集**：MNIST 与 Fashion-MNIST，各 60,000 训练 / 10,000 测试的灰度图像，L = 10 类。[^r4]
- **预处理**：选择特定路径把 2D 像素重排为 1D 序列 $(x_1, \ldots, x_{784})$；单通道 ResMPS（如 sResMPS）不做特征映射，双通道 ResMPS 采用线性特征映射 $(x, 1-x)$。[^r4]
- **训练**：Adam 优化器，学习率 $10^{-4}$，mini-batch 大小 1000；损失函数为交叉熵；dropout 概率 0.6，非线性激活为 ReLU；实现基于 PyTorch。[^r4] 预测规则为取整体映射 $f^{(l)}(\mathbf{x})$ 的最大分量对应的类别。[^r4]

### 局限与未来工作

论文明确列出的未来方向：用卷积层替换权重矩阵以进一步提升精度，以及把 ResMPS 的思路推广到 Tree TN、Projected Entangled-Pair States 等更一般的 NN / TN 结构。[^r3]
