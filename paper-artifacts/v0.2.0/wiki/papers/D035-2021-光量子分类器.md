# Experimental realization of a quantum image classifier via tensor-network-based machine learning

> **作者**：Kunkun Wang、Lei Xiao、Wei Yi、Shi Ju Ran、Peng Xue | **发表**：Photonics Research
> **核心贡献**：首次在单光子平台上实验演示了基于张量网络（tensor network）的量子机器学习方案，对 MNIST 手写数字 "0" 和 "1" 实现二分类，成功率超过 98%。

## Navigation

本文针对当前量子机器学习受限于有效希尔伯特空间维度这一瓶颈，将张量网络表示与基于纠缠熵的优化相结合，把手写数字特征压缩到两比特的光子态中。实验上利用偏振与空间模式双自由度编码，通过单光子干涉仪实现三、五层结构的分类器门操作，并以投影测量读出分类结果。研究还展示了分类器对 MNIST 之外的潦草手写数字的鲁棒识别能力，并指出该方案可推广至氮空位中心、核自旋与囚禁离子等物理体系。

## 研究方向定位

针对真实手写图像的二分类任务，研究如何在有限量子比特条件下基于张量网络机器学习实现高成功率的量子分类器，并在单光子平台上进行实验演示。[^r1]

## Content

### 张量网络机器学习算法

论文遵循标准的 TN-based 监督学习流程：对于含 N 个特征（像素或频率分量）的灰度图像，先通过特征映射将每个特征 xₙ 编码为单比特量子态 $|s_n\rangle = \cos(x_n\pi/2)|0\rangle + \sin(x_n\pi/2)|1\rangle$，得到 N 比特乘积态 $|\phi\rangle = \bigotimes_{n=1}^N |s_n\rangle$。[^r2]

为将图像划分到 N_c 个类别，引入联合希尔伯特空间 $\mathcal{H}_\mathrm{prod}\otimes\mathcal{H}_c$ 中的分类器态 $|\Psi\rangle$，使得图像属于第 c 类的概率为 $P_c = |\langle\Psi|(|\phi\rangle\otimes|c\rangle)|^2$，并以 argmax P_c 作为预测结果。[^r3] 论文采用矩阵乘积态（MPS）表示 $|\Psi\rangle$，将 MPS 张量作为等距变换以直接对应量子电路中的门操作，并通过负对数似然损失函数在训练集上完成优化。[^r4]

### 纠缠熵驱动的特征选择

由于真实图像所需希尔伯特空间维度远大于当前量子平台所能承载的比特数，作者针对二元分类采用 dim(c) = 2、虚拟指标 dim(aₙ) = 2 的 MPS，使分类器复杂度随 N 仅线性增长。[^r5] 在此基础上，论文借鉴 Ref. [25] 的方法，通过纠缠熵公式 (A9) 从原始图像中筛选出在量子特征空间中纠缠熵最大的 3 个或 5 个特征（分别对应三、五层结构），并通过余弦变换将所选特征送入 MPS 训练。[^r6]

### 单光子实验实现

实验上，分类器比特编码于信号光子的偏振态（|H⟩ = |0⟩、|V⟩ = |1⟩），操作比特编码于空间模式（|u⟩ = |0⟩、|d⟩ = |1⟩）。[^r7] 单比特门 U₁ 由半波片（HWP）实现，二比特门 U₂、U₃ 由 HWP 与光束偏置器（BD）级联构成的干涉仪实现；方案 A 通过受控分束器（CBS）将特征态注入网络，特征信息编码于 HWP 的设定角度。[^r7]

训练使用 MNIST 数据集训练集中 12,665 张手写 "0" 和 "1" 图像，训练完成后固定 Uᵢ。测试集共 2115 张图像：三层结构下仅误判 30 张（10 张 "0"、20 张 "1"），成功率 0.9858；五层结构下误判 19 张（4 张 "0"、15 张 "1"），成功率 0.9910。[^r8]

### 多方案对比与鲁棒性验证

论文除方案 A 外，还展示了方案 B 的三、五层实现，四组实验（方案 A 三层、方案 B 三层、方案 A 五层、方案 B 五层）成功率分别为 0.9858、0.9839、0.9877、0.9877，均高于 98%。[^r9] 对于部分测试图像，尽管 3 层结构下难以判别，5 层结构可给出正确结果，表明增加特征空间维度可提升分类表现。[^r10]

在 MNIST 之外的测试中，对一组标准写法及一组特意令 "0" 形似 "1"、并将 "1" 写得短而粗的手写数字，分类器均给出高置信度（|P₀ − P₁| 较大）的正确识别结果，验证了装置对分布外样本的鲁棒性。[^r11] 作者指出，由于余弦变换舍弃了高频分量，该方案对手写图像中的高频噪声同样具有鲁棒性。[^r6]

### 适用体系与展望

论文将所提 TN-based ML 方案视为通用方法，明确指出其可直接应用于具有完整 qubit/qudit 控制能力的氮空位中心、核磁共振系统以及囚禁离子等物理体系。[^r12] 此外，作者提到若将 ML 优化直接作用到器件参数（如波片设定角）而非整体电路设计上，该混合量子—经典方案可升级为完全量子化的方案；并展望在基于超导量子电路的平台上以更大特征空间与更多比特实现更复杂任务。[^r12]
