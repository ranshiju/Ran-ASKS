# 通用建议型审阅：实施与验证计划

## 基线与目标

建设基线为源仓库 `28cc667c` 加当前工作树；保留路由、功能目录及术语更新等已有未提交改动。附件仅供设计参考，不授予工具权限。

交付一个 `artifact.review` 功能：shared 内核负责输入/资产冻结、范围、严格协议、双视图、记录和报告；agent-only 宿主适配负责真实新上下文调用；API 本轮不实现、不登记。reviewer 各自维护方法、可配置语义槽位、反馈结构及样例，不复制执行器。

## 阶段与依赖

1. 契约及宿主探针：明确独立上下文、可见材料和执行层权限三个维度；先登记工程图。探针只用合成材料，结果不证明强沙箱。
2. 最小真实闭环：prepare → 宿主子 Agent → check/collect → report；同时接入功能目录、Route 和 WG。不给盲读者父会话或控制清单。
3. 可靠性与安全：冻结定义及 schema、幂等/冲突接收、中断恢复、失配定位、源稿过时、快照完整性、敏感性及自足存储。
4. 独立演进：reader-comprehension、argument-structure 与仅全文取舍的测试实例；验证旧定义在途升级与新定义并存，旧 PNG/API 展板行为不变。
5. 效果与公开树：合成对照材料、真实宿主运行、离线回归和无私有依赖的发布树验证；明确未做真人有效性验证。

各阶段连续推进，不新增逐步审批。输入权限不明或宿主能力不满足时只停止相关运行，不伪造审阅，也不隐式切换后端。

## 验收与风险

- 无批评配额、分数门槛、自动改稿或意见关闭门禁；技术失败如实报告，不代表作品不合格。
- 通用反馈支持优点、疑问、整体取舍、空意见；角色专属字段不进入公共必填。
- 用户授权、定义上限、全局策略与宿主可强制能力取交集。首版拒绝 private 及未知敏感性；Agent 不等于离线。
- 使用同一冻结输入和资产校验旧任务；源稿更新仅过时，审阅快照改变则失去绑定。
- 仅候选可由子 Agent 产生；身份、执行能力和版本事实由宿主/程序记录，模型不得覆盖。
- 重复接收幂等；冲突保留；恢复不重新调用模型；远程 exactly-once 不作保证。
- 持久记录自足，不依赖清理后的 temp；不自动成为 Raw、Wiki、工作区事项或长期记忆。
- 仅公开合成定义/样例/测试。运行输入、宿主日志和私有个性化配置不进入发布目录。

## 回归

新增离线审阅测试；任务协议、WG、功能注册、展板读者、视觉 helper、公开树、工程图和运行时功能覆盖按影响卡验证。真实宿主测试与 fake backend、语义效果观察、真人测试分列，不相互冒充。

#### 真实宿主合成试点

三次实际新上下文子 Agent 调用均完成 check/collect/report：术语缺口稿的读者视角
返回5项，清晰稿读者返回2项，缺口稿论证视角返回5项；全部原文定位校验无诊断。
清晰稿仍指出与现有搜索比较不足，并非强迫返回“没有问题”。论证角色给出必要性、
推理跳步与组织取舍，未依赖读者专属字段。以上是探索性语义观察，不是统计对照、
因果效果或真实人群有效性验证；意见数量不作质量指标，也未据此改稿。

宿主能创建新上下文，但本次工具限制只有指令约束，没有强制最小权限；模型版本、
用量、处理位置未知处如实记录。合成 canary 的独立追问未报告父会话标记，仅是有限
自报观测，不证明所有隐式上下文均不可见。只使用公开合成材料，不据此放行敏感稿。

包与回复由宿主手工转交，未认证字节级传输：首次指令转写省略行内代码反引号；
一项论证关系转写遗漏一个不改变建议含义的字。已在本地记录偏差，保留既有接收
记录，不静默覆盖。真实调用闭环可用不等于自动传输准确性或强沙箱已获认证。

### 2026-10-23：共享本地渲染与可追溯图片交接计划

问题链：审阅只冻结单张整板，宿主显示层可能缩放；主 Agent 的临时裁图不能作为可重建的局部材料契约。展板还跨组件调用 visual_qa 的私有转换函数。责任组件是 shared 的本地材料准备与 review 交接，不是读者角色或另一个视觉模型。

目标与验收：公开既有本地转换入口，复用 visual_qa 提供有界整图/局部图准备；局部图记录整图坐标、像素范围、来源和输出哈希。PDF 存在且经成品清单绑定时，直接渲染对应局部，不放大低清 PNG 冒充恢复细节。单张整图和历史运行保持原契约；带局部图的新运行逐附件登记交接与可读性，不以一个总布尔值掩盖遗漏。实际显示尺寸只接受显式自报，未知不推定原生分辨率。

边界：新增职责登记到既有 visual_qa/review 组件和功能目录，不新增图片模块或控制循环。shared 只准备、校验和保存材料；Agent 决定是否需要局部、选择区域并原生附图。API QA 与其 DSH adapter 行为不变，不新增模型、网络、自动审阅或重试。

顺序：①公开转换和本地材料 CLI/API；②review 支持显式区域、绑定 PDF 细节来源、匿名多附件 packet 和逐图回执，science-exhibit 转发同一入口；③补充快照漂移、坏区域、遗漏附件、可读性、路径安全、坐标/像素、单图兼容与非物理合成回归；④用当前 MPE 版本只准备真实材料并检查局部，不启动新子agent、不登记预览接受。同步契约、工程指南和 workspace 接续。

风险/验证：附件数量、像素、字节和 JSON 有上限；局部内容是来源数据而非新指令，盲读包不传本机路径、作者答案或旧意见。PNG 局部不增加源信息，PDF 局部也不能消除宿主缩放或证明真实理解。运行 review、visual-QA、展板 workflow、Agent task、WG、功能注册与工程图定向回归；需要时使用实际 render。保留所有已有手改原件、成品及历史记录，不修复无关 prompt-audit 失败。

实施结果：共享公开转换、本地材料 CLI/API、可选 PDF 局部、多附件冻结/交接/逐图可读性及 receipt/report 已接通，功能目录与工程图保持原组件归属。review 41/41、workflow 33/33（含真实 render）、visual-QA、science-exhibit（含 render）、Agent task、功能目录、WG、旧 API reader mock 与公开树回归通过。已知 query-start prompt-audit 仍失败，未放宽阈值。MPE 同内容重导出后整图字节不变，实际准备四图并抽检局部，最终 run 为 prepared、无执行或新意见；旧两次真实单图记录仍可读取。具体证据与接续见 `projects/MPE科普展板/outputs/image-handoff-20261023/README.md`、`validation.json`。未增加模型/API 调用，不把工程完成冒充逐图真实模型验证或真人效果验证。
