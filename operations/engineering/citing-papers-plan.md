# 施引文献获取能力独立化

日期：2026-11-06。目标：让指定论文的施引文献发现、时间快照、去重及导出可被评价、文献调研和后续跟踪复用，保持既有 paper-impact 可用。

## 边界与阶段

1. 先登记工程图，将公开书目发现及候选合并算法移到 shared `citing_papers.py`；原 `paper_impact_discovery.py` 保留兼容导入，paper-impact 直接依赖共享实现。
2. 新增独立 init/fetch/import/list/status/export CLI 和 Python 调用接口。集合位于 projects/citing-papers，不需要评价项目、贡献、人物名单或任何语义 Agent task。仅 fetch 联网，不新增模型 adapter；语义工作仍在下游。
3. 使用相同原子写入/文件锁规则；保存失败、部分分页、来源/日期与首次发现/最近观察时间。导出通用 cited-by 元数据协议，历史并集明确不是当前全量快照，保留批次 provenance 与逐条观察时间。
4. paper-impact 兼容旧导入协议并支持新通用协议；已有状态无需迁移。共享合并算法，离线导出导入不重新联网。
5. 接入 wg、route、功能目录、playbook 和指南。验证独立能力、旧评价闭环、错误/空结果、来源保留、路径和事务边界及工程图。

## 验收

- 在隔离目录完成建档、检索回放、重复更新、分页查看、导出、独立集合及评价项目离线导入；验证没有 Raw/Graph/评价自动生成。
- 已有 paper-impact 回归保持通过，旧协议/模块可继续调用。
- 不扩展到全文下载、摄入、多来源新 provider、自动人物筛选或定时任务；这些是下游或后续可组合能力。
