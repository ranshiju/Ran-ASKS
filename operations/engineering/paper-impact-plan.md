# 单篇论文第三方评价与影响证据：实施计划

日期：2026-11-05。目标是完成 DOI/题名建档、施引文献批次保存、人物/期刊双通道排序、库内全文核对、Agent 取证和可回溯申报报告的闭环。

## 边界与顺序

1. 先登记工程图。新增 `paper_impact` 共享确定性内核和 `paper_impact_discovery` 有界公开书目发现 adapter；语义执行仅由宿主 Agent 完成，使用 agent-task-v1，不接 DSH 或模型 API。
2. 单篇工作区位于 `projects/paper-impact/<id>/`。检索记录是发现线索和审计快照，不是事实源；证据必须回溯 academic Raw。所有 Raw 写入仍由原受管摄入完成。本功能不修改 Raw/Wiki/Graph。
3. 实现 OpenAlex 分页发现及带来源的离线清单导入；保存查询时间、范围、完整性、失败和响应，不静默把部分检索当作全量。DOI 和供应商稳定 ID 去重；不同版本不凭近似题名合并。
4. 实现贡献清单、可配置作者/期刊优先名单、双通道及综合阅读排序；身份未知不冒充权威。库内核对同时覆盖 paper bundles、Wiki 发现桥接及 Source-first receipts，仅 DOI/严格题名可成为匹配候选，正文引用到某 DOI 不代表其自身身份。
5. Agent 任务准备、结构/来源校验、原子提交。评价原文、目标引用映射、贡献关联、中文译文、独立性依据、可用表述/限定/不可支持主张完整保留；来源漂移使旧证据失效。背景/负面/全文不全仍保留，不冒充正面证明。
6. 接入 wg、route 和功能目录，同步使用文档、代码指南；导出 Markdown + JSON 阅读清单、摄入建议和证据报告。

## 验收与风险

- 离线合成回归覆盖分页/中断、重复/增量、同名作者、正刊子刊、引用 DOI 误匹配、版本冲突、只有摘要、来源漂移、错误归属、缺少限定、任务过期、并发和路径边界。
- 完整演示在隔离临时仓库中执行，不往真实 Raw 写入测试数据；真实论文试点须由用户指定目标。
- 验证新功能、wg、Agent task、功能注册、playbook/路由及工程图。现有未提交内容保留；无关失败如实披露，不扩面修复。
- API 配额/认证可能限制真实检索；失败应有明确状态和离线导入路径。机械核验确认原文及来源一致性，不认证语义判断或学术地位。
- 首版不自动下载/摄入、不自动建立人物权威事实、不发布 Wiki、不外发申报材料、不创建定时任务。支持显式重复发现以产生增量。

## 实施与验证结果

已接通 `wg.py paper-impact`、paper-impact capability、功能目录和自然语言 playbook。新增共享内核与 OpenAlex adapter，Agent 使用 configure/evidence 两类任务；支持显式选定库内版本、元数据/部分全文区分、引用编号范围核验、贡献定义与来源变化失效、可重建 Markdown/JSON 证据报告。

- 新增离线回归 49/49 通过，含真实 Source-first 受管摄入在隔离临时仓库中的调用；覆盖保存失败、并发锁、越界、去重、时间顺序、分页、同名、版本、错误引用、引用归属限定和失效证据。
- Agent task 7/7、功能目录 13/13、WG、playbook 派发、工程图回归、公开发布打包回归通过。工程图及运行时目录验证通过（390 节点、784 边、23 能力包；33 功能）。
- 2026-11-05 对公开测试 DOI `10.1038/nphys1170` 实际执行 OpenAlex 查询：2 次请求，返回目标 Measured measurement 的 17 条施引记录，供应商分页完成。没有据此分析或宣称存在同行正面评价，也未把测试记录写入真实知识库。
- 5000 条合成施引记录单次本地观察：批次保存约 0.212 秒，空知识目录下排序约 0.019 秒。仅说明确定性存储/排序路径，非真实全库、网络或 Agent 阅读端到端基准；别名/书目匹配使用内存索引避免二次扫描。
- 申报语义验收仍须用用户指定代表作进行：重点检查高位候选中的可用证据比例、低位抽查遗漏、归属与措辞准确性。工程回归和公开 API 通畅不代替这项实际论文验收。

首版限制：OpenAlex + 来源明确的 JSON 导入；人物/期刊优选名单由宿主基于用户偏好或已摄入事实维护，不自动认证学术地位。联网检索有分页与总字节预算、单项目状态 80 MB 上限；截断/失败明确保留。未加入 PDF 截图、Word 排版、自动摄入、定时跟踪或模型 API adapter。

## 2026-11-06：人物资历复用与代表性初筛

- 目标：支持奖项、院士、学会 Fellow、重要任职与机构的独立记录，建立可复用人物页；阅读报告显示可核实资历和标题相关性/建议理由，不固定扩充篇数。
- 边界：沿用 people 页作为公共人物入口，Raw 仍为事实源。Agent 查官方网页、消歧、撰写人物与初筛内容；shared paper-impact 只校验身份/Raw/哈希/结构、存储配置和渲染报告。建页沿用摄入后的巩固与 graph_ingest 校验，不新增数据库或 API 控制循环。
- 依赖与顺序：先更新工程契约和 people 页定位；实现 configure 中可选 profile_page、screening，以及报告事实种类 → 通过隔离测试 → 官方资料受管摄入、创建样例人物页 → 配置引用及原项目复用验证。
- 风险与验收：同名不能继承荣誉，职务/院士/Fellow 不等同奖项，Fellow 须分辨学会会士与研究职位。页面与原文漂移后停止使用旧资历；未核实身份不赋值。初筛书目改变需重评，不能自动扩展 selection。旧配置/评述兼容；运行 paper-impact、Agent task、WG、注册与工程图检查，并验证真实 Raw→people→候选报告可回查。
- 完成：configure 支持共享 people 页和逐篇 screening；报告分别显示五类资历、时间、来源及初筛理由。绑定作者稳定 ID、人物页和 Raw 指纹，来源或书目漂移后停止展示旧依据。增加 6 项回归，paper-impact 61/61、Agent task 7/7、功能目录 13/13、WG 回归通过；运行时注册表（34 功能）及工程元图（399 节点、821 边、24 能力包）验证通过。
