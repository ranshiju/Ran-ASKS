# 行政文档内容形态示例

> 本文件只帮助选择正文组织方式，不定义 frontmatter、页面类型或运行时输出契约。确定性骨架由摄入程序生成，字段以 `admin/SCHEMA.md` 为准，证据与提交边界以 `operations/INGEST.md` 为准。

## 规范型

适用于政策、制度、程序和正式决定。

```markdown
## Navigation

说明文件性质、核心事项、适用对象、时效状态和常见查询表达。

## Content

### 适用对象与范围
### 核心规则
### 例外与衔接
### 关键时间节点
```

## 事件型

适用于会议、活动和访问记录。

```markdown
## Navigation

说明事件、时间、参与者或部门、核心议题和当前状态。

## Content

### 参与者
### 讨论记录
### 决策记录
### 行动项
### 结果或产出
```

讨论、决定和行动项分别记录，保持语义角色清楚。

## 实体型

适用于个人档案、参考资料和发言稿。

```markdown
## Navigation

说明资料性质、核心属性、时间状态和常见查询表达。

## Content

### 核心属性
### 关键内容
```

各示例均依据 Raw 取舍内容；实际页面保留程序生成的 `Navigation`、`Content` 与证据结构。
