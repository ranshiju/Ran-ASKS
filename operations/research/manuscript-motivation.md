# 论文背景与动机构建

> `academic.manuscript_motivation` 的 `manuscript-motivation/general` capability。宿主 Agent 负责文献核验、科学判断和写作，shared 路由只派发本规范与共享落笔约定。本文是背景与动机方法的单一维护源，摘要与全文改进按需复用。

## 入口与交付

在仓库根目录运行：

```bash
python3 .scripts/route.py --capability manuscript-motivation
```

保持已有研究工作上下文，复用最新认可的标题、核心问题、贡献排序和有效阅读。本入口已组合 `WRITE.md` 的总体原则、共享落笔约定和事实与主张控制，无需重复加载通用 academic profile。其他智能体可运行同一命令，或直接读取本规范及共享写作章节；模型已有知识和语义执行归当前宿主，不依赖作者个人目录、聊天历史或外部模型 API。

默认交付两个可直接用于稿件的候选版本：

- **摘要版：一至两句话。** 凝练关键背景、科学未知与研究意义，原则上供摘要首句或前两句使用；通常不展开文献或列引文。结合整体摘要结构判断其位置，保留核心发现所需篇幅。
- **引言版：两至三段。** 展开理解问题必需的背景、已有认识、尚未解决的问题及解决它的意义，自然引向本文切入点。段落各推进论证，根据论文类型组织，不固定每段模板；具体文献结论附引用。

两版共享科学主线、概念与证据范围。引言版提供完整论证，摘要版保留最必要的逻辑，不把机械扩句或截取前两句当成长度转换。主要内容是背景与动机，不自动重写完整摘要、引言贡献段或结果。

## 输入与证据

确认当前稿件版本、主文与相关图表、参考文献及最新认可的标题、核心科学问题和核心贡献；目标期刊、读者、语言与长度要求优先沿用用户设定。阅读原始摘要、引言、主要结果、讨论及支持关键判断的方法或补充材料，使动机指向标题强调的科学价值、核心问题中的未知和核心贡献实际回答的内容。标题尚未确定时依据问题与贡献推进；定位与证据冲突时指出具体差异，缺少定位时按需组合相应能力。

五类材料各有用途：

| 材料 | 用途与证据边界 |
|---|---|
| 已有稿件 | 理解研究目标、方法、结果与作者意图；现稿中的文献判断仍需核验 |
| 已有引用文献 | 核对已有工作、比较基线与研究不足；参考文献条目或题名本身不证明结论 |
| 模型已有知识 | 组织概念联系、形成论证和检索线索；不充当具体优先权、性能或研究空白的证据 |
| 知识库相关内容 | 通过受管查询定位 Wiki/Graph，再回到原始来源核验事实 |
| 网络来源 | 补充关键证据、近期进展和最接近的已有工作；优先一次论文与正式出版页面 |

先读稿件与已有引用，明确缺口后定向查知识库和网络。用户明确要求使用某类来源时执行相关检索，并如实记录无命中、访问失败或实际覆盖范围；不为凑齐来源塞入无关文献。库内检索无命中不能据此断言文献不存在。网络检索只使用公开的题名、作者、领域概念等线索，不上传未公开稿件或用其独特未公开结论作为查询。

为拟采用的实质性主张保留轻量的“主张—来源定位—支持范围”对应。优先复用稿件中已核验的引用键；新增文献须核对题名、作者、年份及 DOI/稳定链接，并与既有条目去重。只读到摘要时仅采用摘要直接支持的事实；具体方法差异和未研究某问题的判断需查看相应正文。检索摘要、博客、模型记忆与过程日志不替代一次来源。无法核验的内容改为明确待研究的问题、缩小表述或列为待核验，不能虚构引文或写成“尚无人研究”。

引言选文献时主动考虑与主线直接相关的顶刊或领域权威论文，以相关性和证据支持为先，不设数量配额。区分支撑一般背景的文献与最接近本文问题的研究：前者说明重要性或研究潜力，后者用于界定已有进展与待解决问题。保留必要的专业期刊、会议等近邻文献；期刊声望不扩大证据范围，邻近任务或不同自变量的结果不能直接证明本文研究对象上的结论。

## 论证主线

沿“科学背景 → 关键未知 → 解决它的意义 → 本文切入点”组织，围绕一条与标题、核心问题和首要贡献一致的科学主线。解释已有进展为何仍不足以回答核心问题，以及回答它将改变什么科学认识或能力判断。动机力度来自这一具体论证，不靠“亟待研究”“明确范围与边界”等泛泛表态或夸大空白。

准确区分尚未研究、已有结论不一致、证据范围有限和缺少可靠测量。承认已有工作的真实进展，研究价值可以来自厘清规律、界定适用条件或提供可检验性，不必依赖绝对空白。可从已有收益与未验证条件之间的关系寻找科学张力，例如性能提高是否伴随更有利的变化规律；选择与本文证据相符的关系，不将具体论文的机制解释固化为通用模板。

核心贡献应回应前文提出的未知；比较、基准和技术流程按其实际贡献地位展开，服务于科学问题。可用尚未解决的机制解释问题为何不显然，但不承诺本文未开展的机制验证。动机可讨论较一般的问题，本文切入点与结论仍明确实际研究范围；待检验假设不写成已有事实，已有优势不预设为普遍成立。

## 写作与回查

英文论文以英文成稿质量为准；中文讨论或中文稿件按用户当前要求交付。需要中文对照时置于相应版本下，保持论证和主张强度一致。使用稿件已有引用格式；摘要版通常无行内引文，其文献依据可在简短来源说明中列出，引言版在相关判断处引用。

先保证科学论证成立，再压缩到约定长度：删去泛泛背景、重复意义和过早展开的技术细节，保留概念清晰、关键未知及其后果。与原始摘要和引言比较问题提出的直接性、科学聚焦和证据准确性，保留原文有效内容，不默认新版更好。

交付前回查：标题、核心问题与贡献是否由同一动机串联；为何已有进展不足、回答问题有何意义是否清楚；两版是否简练且范围一致；引用是否支持紧邻判断。避免把文献数量当作证据强度，或把已有能力包装成本文创新。默认主体只给两个版本，来源说明和真实缺口简短附后；用户仅要求其中一版或比较时按当前请求交付。

用户要求应用到稿件时交付两版候选；保存到授权项目目录或按项目约定保留草稿，不把用户论文写入公共功能示例。替换原稿按用户授权和版本约定执行，复用相应文档构建检查；仅给候选时不自动覆盖主文。连续改稿复用未变的文献核验结果，新增科学主张才补查相关证据，不自动摄入、投稿或发送给他人。
