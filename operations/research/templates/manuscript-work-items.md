# 论文持续工作事项正文模板

用于 `workspace_state.py item add/update --stdin` 的内容示例，按实际需要精简。ID、状态、下一步等结构化字段由受管命令写入；本模板不另建状态文件、schema 或审批流程。项目内路径优先相对工作区根目录，文献标识与 locator 使用实际返回值。主文文件名遵循[主文档命名规范](../manuscript-improvement.md#主文档命名与版本)。

## manuscript 类型：论文主事项

```markdown
## 稿件与比较基线
- 原稿或版本快照：路径/版本及保存时间。
- 短名与当前版本：稳定短名、vN。
- 当前主稿：<短名>_vN.tex/docx；对应导出：<短名>_vN.pdf；是否已整合候选。
- 上一版及历史映射：路径；首次规范旧名时记录旧名与新名的对应。
- 当前候选：路径、版本、修改范围与认可情况。
- 参考文献、图表与补充材料：路径。

## 定位与授权
- 目标期刊、语言、任务范围；未知项明确保留。
- 最新认可的科学问题、贡献及标题：关联的工作区记忆 ID。
- 本轮允许修改的文件/章节，候选与替换的约定。

## 进度与验证
- 已完成及产物地址。
- 实际阅读覆盖和证据依据；哪些材料需要补读。
- 已执行检查及其范围，未完成检查如实标明。
- 与原稿/上一版的主要收益与取舍。

## 接续
- 剩余章节或问题及优先顺序。
- 文献/研究证据缺口：相关事项 ID；是否影响某一主张。
- 当前具体下一步与恢复位置。
```

## question 类型、literature 标签：文献需求

```markdown
## 文献与需求
- 题名、作者（已知时）、DOI 或稳定链接。
- 所需材料：全文、附录、数据或特定段落。
- 需要核验的具体论断与影响章节。

## 已有证据与依赖
- 已读/已核验范围及来源 locator。
- 库内与公开来源查找结果；访问失败如实记录。
- 阻碍哪个论断，哪些工作仍可继续。
- 用户需提供什么；当前是否已授权摄入及授权范围。

## 恢复位置与完成依据
- 论文主事项 ID、稿件版本、章节或段落。
- 摄入完成后填写真实来源标识与 Raw/Wiki locator；未摄入不填猜测路径。
- 原文核验结论、引用及主张的调整；尚未解决的部分。
- 下一步：回到哪个写作位置，或继续查证什么。
```
